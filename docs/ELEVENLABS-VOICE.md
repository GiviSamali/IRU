# ElevenLabs: Arcadays / Eleven v4 Turbo

Отдельная ветка codex/elevenlabs-voice. Добавлен третий обработчик в существующее меню. Яндекс остаётся по умолчанию, Piper доступен вручную; автоматического перехода между платными провайдерами нет. Агент обновлять не нужно.

Переменные окружения процесса сервера:
- ELEVENLABS_API_KEY — ключ с правом Text to Speech, задаётся только на сервере.
- ELEVENLABS_VOICE_ID=s0phbFBBp708ZeIy8oGx
- ELEVENLABS_MODEL_ID=eleven_v4_turbo (по умолчанию)
- ELEVENLABS_STABILITY=1.0 (по умолчанию)
- ELEVENLABS_SIMILARITY=1.0 (по умолчанию)

У модели v4 нет прежних style/speed/speaker_boost: отправляются stability и similarity_boost. Стартовые значения 1.0 выбраны по имени присланного MP3 (s100/sb100), точные значения UI по картинке не определялись.

Используется официальный Text to Dialogue WebSocket, один голос и одна готовая реплика. Сервер получает MP3 44.1 kHz/128 kbps и возвращает audio/mpeg существующему проигрывателю. Никаких ElevenAgents, переноса LLM, распознавания, новых устных текстов или дополнительных LLM-вызовов. Выбор ElevenLabs не включает правило ударений Piper. Уже имеющиеся знаки ударений Piper удаляются только из входа ElevenLabs; журнал и письменный ответ не меняются.

Ограничения: 900 символов на часть, 30 секунд на запрос, 4 MiB аудио и 256 сообщений провайдера. Без повторного платного запроса при ошибке. Существующие проверки владельца задачи, nonce/ревизии, ограничения скорости и активной озвучки сохранены. Ключ и ответы провайдера не передаются в UI и не логируются адаптером.

Протокол: https://elevenlabs.io/docs/eleven-api/guides/how-to/websockets/realtime-tdd
Настройки: https://github.com/elevenlabs/skills/blob/main/text-to-speech/references/voice-settings.md

До приёмки требуется живой запрос: документация guide поддерживает v4 Turbo, API-reference частично описывает старый v3. Ключа нет — доступ к выбранному голосу, расход кредита, параметры голоса и фактическая скорость ещё не проверены. Внешняя скорость модели не равна задержке всего ответа IRU, поскольку текущий проигрыватель ждёт готовое аудио.

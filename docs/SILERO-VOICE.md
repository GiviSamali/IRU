# Silero: озвучка ответов на компьютере

Ветка `codex/silero-voice` создана от `codex/chat-recovery-p0`.
Нужны обновлённые сервер, UI и агент; старый агент не поддерживает `voice.synthesize`.

1. В меню агента: «Настройки агента» → «Пере-настроить» → «Дополнительно».
2. Указать Python с torch/soundfile и скрипт, принимающий текст аргументом и создающий PCM `output.wav` в текущем каталоге.
   Существующее окружение IRU и say.py на Desktop/OneDrive Desktop подставляются при открытии настройки, если найдены.
3. В настройках ИРУ выбрать «Озвучка ответов → Silero» и свой подключённый компьютер.
4. Включить голосовой режим и попросить короткий ответ. WAV приходит через сервер в существующий проигрыватель UI.
5. Проверить «стоп», переключение обратно на Яндекс и ошибку при отключённом компьютере.

Выбор обработчика хранится в браузере отдельно для каждого аккаунта. Пути хранятся только в конфигурации агента. Сервер не принимает пути/команды синтеза из запроса. Текст берётся только из существующей разрешённой озвучки задачи; проверки владельца задачи, устройства, подтверждения и ревизии сохранены. Никакого автоматического перехода на Яндекс.

Скрипт запускается без shell, stdout/stderr не передаются и не записываются. Каждый запрос получает отдельную временную папку; существующий output.wav на рабочем столе не перезаписывается. Ограничения: 900 символов на часть, 50 секунд на скрипт, WAV до 4 MiB (base64 до 5.34 MiB). У агента существующий WebSocket лимит 8 MiB. Синтез не добавлен в инструменты LLM и не является доказательством выполнения задачи.

Модель загружается самим существующим скриптом при каждом вызове. Поэтому первая и повторные озвучки могут быть медленнее Яндекса. Скачивание/кэширование модели остаётся поведением локального скрипта; интеграция не устанавливает зависимости. Постоянный процесс модели не добавлялся.

# CHAT RECOVERY P0 — локальный diff

Ветка: `codex/chat-recovery-p0`, база `origin/main` на `97a05c8`.

## Изменения

- `ui/index.html`: прежний Dock перенесён в правую Tasks; добавлен компактный Mirror, кнопки закрытия. Идентификаторы ввода, голоса, PLAN и навигации сохранены.
- `ui/js/operations.js`: прежний опрос `/api/operations` и `/api/tasks/{id}` остаётся единственным источником. Задачи фильтруются по текущему чату, группы соответствуют API. Mirror следует активной задаче до явного выбора пользователем. Закрытие не отменяет задачу; новая активная задача появляется автоматически. На потерю связи выводится последнее состояние, решения блокируются до обновления.
- `ui/css/operations.css`: независимый скролл Tasks/Mirror, Conversation использует оставшуюся ширину; на узком экране панели overlay, ввод поверх панелей.
- `ui/js/chat.js`: контекст выбора сбрасывается при смене чата/аккаунта. Файлы Worker доступны в раскрываемой секции, не вытесняют текст ответа.
- `server/response_presentation.py`: единственная backend-правка. Успешный нормализованный report + audited_terminal receipt + goal_completed=true + verified + валидный текущий basis возвращают точный терминальный текст перед старым presentation cache и выбором артефакта. Нет новых доказательств/полномочий, нет изменения статусов или журнала.

Mirror сейчас показывает нейтральную иконку задачи, исходное название поручения, устройство, текущий статус, ответ, существующие действия и раскрываемые файлы/журнал. Предпросмотр и проценты не добавлены. Главный объект не угадывается по вспомогательному .ps1. Расширение представления Mirror не требует изменения источника задач.

## Переиспользование и границы

IRUOperations, IRUSmartUI, renderSmartTaskDetails, прежние файловые действия и защищённые endpoints command-decision / review-plan / cancel. Перед решением проверяются именно показанные nonce/команда или revision; обновлённые параметры не подставляются вместо просмотренных. Сервер сохраняет окончательное решение об авторизации.

Orchestrator, Worker, Scheduler, Agent, Browser Bridge, БД, API и голосовые модули не изменены. Открытие/закрытие панелей не вызывает голосовых функций. Имеющаяся остановка голоса при переключении чата сохранена.

## Проверки владельца

Тесты подготовлены, НЕ запускались. Проверены только синтаксис JS/Python и git diff --check.

```bash
python -m pytest tests/test_response_presentation.py -q
node --test tests/chat-recovery-browser.test.cjs
```

Браузерный набор требует имеющийся Playwright/Edge. Он использует существующий mock-сервер и не обращается к пользовательским устройствам/LLM/TTS.

Живая приёмка:

1. Новый чат без задач: весь свободный экран Conversation, обе панели закрыты.
2. Поручение: Mirror появляется; новое сообщение отправляется во время работы.
3. Tasks: реальные группы и очередь, выбор другой задачи, независимое закрытие.
4. Закрыть Mirror: задача продолжает работу; открыть выбранную задачу снова.
5. Подтверждение команды/PLAN: увидеть текст, принять/отклонить; при изменении nonce/revision старое решение не отправляется.
6. Завершение: содержательный ответ в чате; вспомогательный скрипт только в файлах/подробностях. partial/unknown не превращаются в success.
7. Сменить чат и аккаунт: чужая задача/подтверждение не остаются видимыми; сетевой ответ старого контекста не возвращает их.
8. Потеря соединения: последнее известное состояние с предупреждением, нет фиктивного прогресса.
9. Скролл истории, Tasks и Mirror независим; ввод, вложения и голос доступны на широком и узком экране. Открытие панелей не переинициализирует голос.
10. PLAN, левая навигация, настройки, память и проводник продолжают работать.

Не объявлять готовность к демонстрации до проверки владельцем в браузере.

# Piper — запасная озвучка вместо Silero

Яндекс остаётся основным и выбран по умолчанию. Piper выбирается вручную в настройках ИРУ; автоматического переключения нет.
В настройках агента указать Python с piper-tts и settings.json из piper-preview. Если пробное окружение найдено в Desktop/IRU/piper-preview, пути предлагаются при пере-настройке агента.
settings.json сохраняет настройки модели, темпа (speed), громкости и вариативности; относительный путь модели считается от папки настроек.

Выбранный provider передаётся в существующий запрос чата. Только при Piper существующий вызов Оркестратора получает правило: spoken_response с U+0301 после ударной русской гласной. Письменный answer не меняется. Никаких дополнительных LLM-вызовов, редактирования готовых реплик/подтверждений или принудительной расстановки ударений в старых ответах. Проверки содержания spoken_response сравнивают текст без знаков ударения, возвращая исходную произносительную форму.

Piper запускается из настроенного Python без shell. Настройки и пути не поступают из запроса сервера. Один процесс на запрос, как в прежней интеграции Silero: постоянный процесс модели в этой итерации не добавлен. Поэтому скорость отдельного ответа включает загрузку модели. Для настройки голоса интерактивный say_piper.py остаётся отдельной пробой с моделью в памяти.
Текст до 900 символов; 50 секунд на синтез; PCM WAV до 4 MiB; временная папка удаляется. Существующий проигрыватель, ограничения владельца задачи/устройства, nonce и ревизии сохранены.

Проверки подготовлены, не запускались:
`python -m pytest tests/test_piper_voice.py tests/test_voice.py -q`

Живая проверка: обновить агент и сервер, выбрать свой ПК и Piper, произнести короткий вопрос. Проверить spoken_response в задаче, обычный письменный ответ, воспроизведение и возврат на Яндекс. Ответы Worker и готовые реплики не обязаны иметь ударения: их текущий путь не менялся.

## Независимые фильтры

«Вид → Уровни» показывает checkbox для каждой фактической глубины `node.level`. Предустановки: «Все», «Только выбранный уровень», «До уровня N», «От уровня N», «Сбросить фильтр». N выбирается из глубин текущего снимка. «Вид → Типы узлов» — отдельный набор checkbox по реальным `node.type`; глубина не подменяется типом.

Например, выберите N=2 и «Только выбранный уровень»: граф содержит только кандидатов глубины 2, без автоматического ядра/родителей/дочерних функций. Для произвольного набора используйте checkbox. Фильтр component может включать компоненты любой глубины; совместно с depth=2 отображается пересечение.

Модель остаётся полной. Приоритет: раскрытие/full → фильтры глубины и типа → рёбра с видимыми концами и выбранными типами → подсветка. `filterNodes`, `displayedNodes`, `displayedEdges`, `levelPreset` находятся в model.mjs. null означает отсутствие ограничения, пустой Set — ничего не выбрано. Снимок, семантические определения, extractor, IDs и координаты не изменяются.

«Полный граф» изменяет только раскрытие, не отменяя depth/type. Фокус и выделение не добавляют скрытые вершины. «Сбросить оба фильтра» восстанавливает кандидатов текущего раскрытия; отдельный reset уровней сохраняет type filter. «Overview / первоначальный обзор» одним действием возвращает исходное раскрытие, снимает node filters и временные исключения.

Если выбранные уровни ещё не раскрыты, честно показывается пустое представление с предложением включить Full. Автоматического переключения Full при настройке фильтра нет.

## Скрытые результаты и отношения

Дерево и поиск продолжают использовать весь снимок, независимо от визуальных фильтров. Скрытый выбранный результат предлагает «Временно показать узел» или «Добавить его уровень / тип». Второе действие явно расширяет текущий выбор, а не заменяет его; первое добавляет только нужный ID в отдельный temporary Set, без родителей и потомков.

Путь вычисляется по прежней полной модели. Если его участники скрыты, предложено «Временно показать маршрут». Это не переписывает depth/type настройки. Видимость дополнительных участников отмечена в индикаторе и снимается отдельным действием. Изменение фильтра очищает temporary exceptions, чтобы новый строгий выбор снова действовал без неожиданных узлов.

Рёбра отображаются только при двух видимых концах. Скрытые промежуточные уровни не заменяются визуальными мостами. Если прямых рёбер выбранных типов нет, это явно сообщается. Существующие `depends_on` сохраняются как проверенная агрегированная проекция: происхождение обозначено в меню и число таких рёбер — в индикаторе; их evidence остаётся доступным в прежних карточках/маршрутах.

Глобальные фильтры связей действуют и при диагностической/маршрутной подсветке. Если вычисленный путь включает скрытый тип ребра, показывается объяснение и кнопка открытия edge filters, без изменения найденного пути.

Аномалии по умолчанию по-прежнему считаются по полному snapshot. Только явно выбранный displayed subgraph использует финальные видимые ID и типы рёбер; его область помечена как подграф с фильтрами уровней/типов. Неполный подграф не выдаётся за полную картину зависимостей.

Execution importer, события, курсор, скорость, source validation и управление проигрыванием сохранены. В фильтрованной сцене скрытые участники/рёбра не рисуются; timeline и доказательства остаются доступны, с явным предложением временно показать участников текущего события. Фильтрация не создаёт новые Trace transitions.

## Верхнее меню

Сохранены Architecture | Relationships | Execution. Управление из viewport перенесено в header:

- **Вид:** Overview, общий вид, ядро, созвездие, full, уровни, типы, сбросы фильтров/temporary, качество, свечение.
- **Навигация:** дерево, сведения, фокус, родитель, раскрытие/сворачивание, сброс выделения.
- **Анализ:** аномалии, путь, direction/transitive, edge filters, сброс диагностики/пути.

Прежние ID команд и onclick/state сохранены; уровни меню управляют только открытием и фокусом. Сбросы диагностики и пути вынесены в общие именованные функции, используемые и меню, и существующими панелями.

Меню реализованы native details/summary: мышь, Tab, Enter/Space и Arrow Up/Down. Esc закрывает меню с возвратом фокуса, не снимая выделение. Click вне header и выбор обычного действия закрывают dropdown; checkbox/предустановки оставляют окно настройки открытым. На узком экране три группы собраны в «Меню», без дополнительной полосы управления внутри сцены.

Активный full/path/mode и фильтры имеют индикаторы. Строка состояния показывает выбор уровней/типов, число узлов/рёбер, агрегированные рёбра и temporary IDs. Дерево и сведения первоначально закрыты и переключаются независимо. Сфера не переработана; изменена только необходимая видимость отдельного core accent, чтобы скрытый уровень 0 действительно не рисовался.

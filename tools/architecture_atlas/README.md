# IRU Living Architecture v0.1

Отдельное локальное read-only приложение. Production-код, API, пользовательские данные и устройства IRU не изменяются. Снимок основан на `codex/agentshell-webview`, HEAD `dbca16b5fa05666758054536b818e951bc5d0779`.

## Запуск

Нужен Node.js 20+ и npm либо pnpm. Из корня реального репозитория:

```powershell
cd tools/architecture_atlas
npm install
npm start
```

Открыть http://127.0.0.1:8765. Сервер слушает только loopback и обслуживает только папку атласа. Зависимость — Three.js 0.180.0; после установки всё отображение и импорт работают локально, без CDN. В окружении Codex вместо npm доступны:

```powershell
& 'C:\Users\russa\.cache\codex-runtimes\codex-primary-runtime\dependencies\bin\fallback\pnpm.cmd' install
node scripts/serve.mjs
```

## Исследование

Первоначально показаны ядро, семь логических подсистем и реальные модули. Двойной клик раскрывает потомков в том же графе. Один клик выделяет непосредственные зависимости. В панели можно свернуть узел, перейти к родителю, выбрать входящие/исходящие или транзитивные зависимости. Поиск работает по всему снимку, включая скрытые функции. «Полный граф» включает все уровни. Обычная мышь вращает камеру, колесо масштабирует, правая кнопка перемещает.

Тусклые структурные линии показывают вложенность. Архитектурные рёбра — импорты и статически разрешимые вызовы. Направленный путь строится только по существующим рёбрам выбранных типов. Раскладка детерминирована ID и не меняется при выделении. Узлы инстансированы; рёбра сгруппированы в LineSegments, смежность индексирована. Качество меняет плотность пикселей. Производительность на тысячах узлов ещё не измерена.

## Execution Explorer

В режиме Execution выбрать локальный JSON (не более 5 MiB, не более 10 000 событий). Поддерживаются:

- нормализованный Trace с `events`;
- диагностический снимок задачи с `diagnostic_trace`;
- снимок с `commands`, `worker_report`, `presentation`, напрямую или внутри `task`.

Для нормализованного формата:

```json
{
  "trace_id": "local-run",
  "architecture_version": "FULL_GIT_SHA_FROM_ARCHITECTURE_JSON",
  "events": [
    {"id": "1", "sequence": 0, "component_id": "EXISTING_SOURCE_NODE", "event_type": "operation", "status": "success", "evidence_reference": "local:snapshot#1"},
    {"id": "2", "sequence": 1, "component_id": "EXISTING_TARGET_NODE", "related_edge_id": "EXISTING_EDGE_ID", "event_type": "operation", "status": "success", "evidence_reference": "local:snapshot#2"}
  ]
}
```

Импульс проходит по ребру только при совпадении версии снимка, существующем подтверждённом ребре и соответствии соседних событий его направлению. Отсутствующий компонент, неизвестное ребро или неполный журнал сохраняются как разрыв; промежуточные участники не достраиваются. События должны иметь неубывающие sequence/время и уникальные ID. Время может отсутствовать. Снимки отчёта/представления добавляются как доказательства без утверждения времени или причинного перехода. События штатного журнала отображаются на модуле-производителе `run_journal.py`, а не на предполагаемом исполнителе. Если есть `diagnostic_trace`, он имеет приоритет над `commands`.

Доступны запуск/пауза, шаги назад/вперёд, ползунок, выбор события, скорость и фокус. Интервал воспроизведения условный (1.2 секунды на событие); это просмотр последовательности, не точная реконструкция длительности или параллельности. DEMO / SYNTHETIC — отдельная явно подписанная проверка интерфейса по существующему статическому ребру, не реальное выполнение.

Импорт никогда не выполняет команды и не отправляет данные серверу. Текст рендерится через textContent. Произвольные аргументы, команды, stdout и тексты результатов не показываются; доступны только ограниченные метаданные результата. Типовые credential-паттерны редактируются, но используйте предварительно обезличенные диагностические снимки: автоматическое обнаружение всех секретов невозможно. Не открывайте произвольные приватные журналы.

Серия одинаковых операций сохраняется отдельными событиями с `step_id`; события не дедуплицируются. Для случая HTML → execute_cmd → Worker Report → Presentation можно импортировать доказательства этих этапов, если они реально присутствуют. Без исходной трассы точку превращения результата в карточку `.ps1` установить нельзя. Эта версия отображает тип/количество артефактов, а не сырые содержательные ответы; сравнение полного текста результата и выбранного артефакта пока не реализовано.

## Обновление снимка

Из папки приложения:

```powershell
python scripts/extract.py
```

Если Python отсутствует в PATH:

```powershell
& 'C:\Users\russa\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts/extract.py
```

Можно указать `--repo PATH --output PATH`. Извлекатель читает только отслеживаемые исходники server, agent, ui, browser_extension; не импортирует Python-модули IRU и не читает базы/логи. Каждая сущность хранит path, symbol, строки, SHA, confidence и объяснение. ID основан на пути и квалифицированном символе, а не позиции. Коллизии повторных определений отражаются в coverage.parse_errors; первая сущность сохраняется. Python AST извлекает классы/функции, импорты и именованные вызовы; динамический dispatch не разрешается. Назначение подсистем — эвристическая логическая классификация.

## Покрытие и ограничения

Снимок: **1 174 узла**, **1 048 Python-сущностей**, **118 модулей**, **92 Python-файла**, **1 549 статических рёбер**, ошибок разбора **0**. Все 1 549 рёбер подтверждены исходниками как статические зависимости; подтверждённых runtime-переходов **0**. Модули JS/HTML присутствуют, символы и вызовы JS ещё не извлекаются. Центральный путь раскрывается до `orchestrator.run_turn`, `worker_presentation`, `build_worker_report`, функций журнала и их доступных статических зависимостей.

Полного цифрового двойника пока нет. Не покрыты динамическая маршрутизация, event bridges, разрешение методов через типы, фактические контрактные входы/выходы и границы полномочий. Нет production-подключения, точного временного проигрывания, параллельных импульсов, автоматической реконструкции маршрутов из неполных журналов и bloom postprocessing. Реальная трасса не предоставлена; восстановленных реальных маршрутов нет.

Отдельный read-only атлас: Architecture Semantics + Spatial Engine поверх v0.1. Одна модель объединяет функциональную архитектуру и физические реализации. Основная IRU, устройства, данные и API не изменяются.

Снимок: `ee3cc4971e5b88f9853e36cef38e7e986f7fd858`, `codex/agentshell-webview`. **1 233 узла / 3 272 ребра**; прежние **1 174 узла / 1 549 статических рёбер** сохранены. Установлены **19 компонентов / 34 механизма**. Runtime observed transitions — **0**.

## Запуск

Node.js 20+, npm/pnpm. Из репозитория:

```powershell
cd tools/architecture_atlas
npm install
node scripts/serve.mjs
```

Открыть http://127.0.0.1:8765. Сервер слушает loopback и обслуживает папку атласа. Three.js 0.180.0 — единственная зависимость; после установки всё локально, без CDN. В окружении Codex:

```powershell

& 'C:\Users\russa\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' scripts/extract.py
```

## Навигация

Клик выделяет узел и точные входящие/исходящие отношения; двойной клик раскрывает потомков и плавно фокусирует камеру. Панель показывает назначение, ответственность, роли, реализации, входы/выходы, границы доверия, evidence и неизвестные сведения. Все вторичные implements-роли доступны из панели без копий исходников. Основной родитель модуля — первая проверенная привязка; другие механизмы доступны через отношения.

«Архитектура» возвращает обзор компонентов. «Полный граф» включает все узлы. «Исходники» переключает дерево на физические реализации. Поиск видит скрытые узлы. Фильтры типов/направлений, транзитивный обход и маршруты используют существующие отношения; список переходов позволяет рассмотреть каждый шаг. Это статический архитектурный путь, не runtime trace.

Мышь вращает камеру, колесо масштабирует, правая кнопка перемещает. «Ядро», «Созвездие», «Фокус узла», «Общий вид» сохраняют ориентацию при плавном переходе. Подписи зависят от роли/расстояния, максимум 80. Свечение управляется отдельно. Выбор и раскрытие не меняют координаты.

## Семантика и обновление

`scripts/extract.py` читает tracked исходники server/agent/ui/browser_extension и строит AST graph, не импортируя production-модули. `scripts/semantic_catalog.py` — поддерживаемый каталог проверенных определений; `scripts/semantics.py` добавляет роли, implements, contains и агрегированные depends_on с evidence. Отсутствующая привязка вызывает ошибку. Неклассифицированные модули остаются явно inferred.

Обновление: `python scripts/extract.py`, при необходимости `--repo PATH --output PATH`. После изменения кода проверьте каталог/evidence. Implementation/static edge IDs сохраняются для неизменившихся сущностей. Схема снимка — 2. Координаты стабильны для одинакового полного снимка; новый состав семейства может изменить раскладку.

Confirmed source, verified architectural mapping, static dependency, logical taxonomy и inferred различаются. Агрегированные зависимости ссылаются на исходные статические рёбра. Ни одна новая функциональная связь не считается runtime observed.

## Execution Explorer — совместимость v0.1

Импорт JSON до 5 MiB / 10 000 событий работает локально. Поддерживаются Trace events, task diagnostic_trace или commands, worker_report/presentation snapshots. diagnostic_trace имеет приоритет над commands. Неполные/неизвестные переходы остаются gaps; участники не достраиваются. Sequence/время неубывающие, event IDs уникальны.

Импульс разрешён только по явно указанному исходному ребру, согласованному с соседними событиями и architecture_version == git_sha. Semantic edges исключены. Версия трассы не меняется автоматически: старый SHA сохраняет доступные события/ID, но переходы не переутверждаются для нового снимка. DEMO / SYNTHETIC остаётся отдельно подписанной синтетической демонстрацией.

Сохранены timeline, pause/steps/speed/event focus. Условный интервал — 1.2 s на событие; точные длительности/параллельность не реконструируются. Команды не исполняются. Поля отображаются через textContent; command/arguments/raw stdout/results не выводятся. Используйте обезличенные snapshots: автоматическое выявление всех секретов невозможно. Execution Mapping в v0.2 не разрабатывается.

## Проверки и ограничения

Тесты подготовлены, **не запускались**:

```powershell
node --test tests/*.test.mjs
python -m unittest discover -s tests -p 'test_*.py'
```

Выполняются только разрешённые JS/Python syntax и git diff --check. GPU/FPS, browser interactions и test suite без отдельного разрешения не проверялись. 83 модуля ещё без проверенной функциональной принадлежности; JS извлечён до модулей; dynamic/event/callback dependencies неполны; отдельные provider adapters не установлены. Раскладка не гарантирует устранения всех пересечений. Полный цифровой двойник не объявляется завершённым.
